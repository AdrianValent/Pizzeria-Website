# Pizzeria-Website
This is one of the first websites I ever made when I started my journey into web development.
I consider this to be my first ever website that I completed, despite it lacking user experience features such as adding items to the shopping cart.
The reason is simple: it's a static website that is fully responsive, and the first website where I implemented responsive design.

I wouldn't consider any of my previous websites before this one completed, because I think responsive design is a must-have for any website to make it truly functional.
The purpose of this website is simply to show off the skills I learned after going through an HTML & CSS course.
This website also contains a little bit of JavaScript, which serves its purpose in making the user experience with the navigation bar clear when viewed on devices with smaller screens.

I wanted to make my approach to creating this website as professional as I could at the beginning of my journey and not risk any legal issues with copyright.
